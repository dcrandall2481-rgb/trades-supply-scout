# Affiliate applications

Do this in your own accounts. Networks approve people, not GitHub repos.

## Before you apply

- Legal name or LLC name
- US tax form (W-9)
- Website or this GitHub README as the property you will promote
- Traffic description: Grok Bot / Cursor plugin that outputs merchant product links for trades materials

## Home Depot

Program page: https://www.homedepot.com/c/SF_MS_The_Home_Depot_Affiliate_Program

Typical network: Impact. Confirm current terms in Impact before you count on a rate.

## Ferguson Home

Program page: https://www.fergusonhome.com/support/affiliates

Also Impact. Confirm current commission in the network terms.

## Rules for this plugin

- Disclose affiliate links in the comparison footer.
- Never reorder a table to favor a tagged merchant over a lower posted price.
- Keep a plain-URL mode so the plugin works before any program is approved.
- Do not sell user job lists to a network.
